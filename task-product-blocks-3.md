# Задача: две малки промени в продуктовите блокове (по DELTA Pro 3) + внос

Съдържанието е в `content/delta-pro-3/sadarzhanie.json`. Две секции на
оригинала не се покриват от блоковете както са.

## 1. `tabbedShowcase` — `tabs-top` да показва `caption`

В оригинала на DELTA Pro 3 („Тих комфорт…“, „Усетете сигурността…“)
разделите са над снимката, а под снимката има текст, който се сменя с
раздела. Сега в подредба `tabs-top` полето `caption` не се показва.

- Ако `caption` е попълнен → показва се под снимката, центриран, макс.
  ~900 px, сив, както `intro`. Ако е празен → нищо (DELTA 3 остава
  както е).

## 2. `comparisonTable` — поле `intro`

Текст под заглавието (textarea, „Текст под заглавието“, по избор), както
при `tabbedShowcase`. Вносът го подава. Миграция: една колона.

## 3. `faqBlock`

Блокът съществува в `src/blocks/product/FaqBlock.ts`. Провери, че се
рендерира на страницата (акордеон: въпрос → отговор, по един отворен)
и че вносът го приема с `items[].question/answer`. Ако няма компонент —
направи го; стил като останалите секции, макс. ширина ~900 px.

## 4. Внос

`npm run generate:types`, `npm run migrate`, после
`npm run import:product delta-pro-3`. Нов продукт → чернова; 7 снимки в
галерията, 24 файла в `sekcii`, категория „DELTA Pro серия“
(`delta-pro-seriya`). Другите продукти не се пипат.

Колоната „EcoFlow DELTA Pro“ в сравнението остава с ръчното име —
продукт `delta-pro` още няма.

## Правила
Никакви нови зависимости; `npm run migrate`, не `payload migrate`; не
пипай съдържанието в базата на ръка.

## 5. Git

След вноса: `git status`, commit на всички промени в кода, миграциите и
`content/*/*.json|*.md|*.txt` с описателно съобщение, `git push`.
`content/*/galeriya/` и `content/*/sekcii/` → в `.gitignore` (снимките
се свалят отново по `snimki-za-svalyane.txt`; пазят се в архива заедно
с `media/`). Това е последна точка на всяко задание отсега нататък.
