# Задача: вносът публикува направо; без „Няма снимка“; без „от“ в картите

## 1. Публикуване при внос

Досега: нов продукт → чернова, собственикът публикува на ръка. При
15 продукта на партида това е излишна стъпка — собственикът реши
продуктите да излизат публикувани.

- `import:product` и `import:all`: **нов продукт се създава публикуван**
  (`_status: published`). Съществуващ — както досега (публикуван остава
  публикуван; ако някой нарочно е върнат в чернова от админа, остава
  чернова).
- Нов флаг `--draft` връща старото поведение (нови → чернова) за
  случаите, когато собственикът иска да прегледа първо.
- Обобщението изписва „създаден и публикуван“ / „създаден като чернова“.
- Опиши в CLAUDE.md.

## 2. Сравнителна таблица — колона без снимка

На `/kategorii/sgavaemi-paneli/solaren-panel-110w-lightweight` блокът
`comparisonTable` показва „Няма снимка“ в колоните, които не са вързани
към продукт и нямат снимка. Заместителят е за админа, не за посетителя:
при липсваща снимка колоната се рендерира без картинка (само етикет и
подзаглавие), без празно поле и без текст. Същото за `inTheBox` и
всички блокове, където има такъв заместител на живия сайт.

(За 110W и 400W Lightweight съдържанието вече е с картинки на колоните —
след `import:all` ще се появят; правилото е за бъдещи случаи.)

## 3. Картите с продукти — без „от“ пред цената

Картите (категорийна страница, карусели, редове с банер, търсене)
показват „от 159,00 €“. При нас всеки продукт е с една цена — „от“ се
маха навсякъде: само „159,00 €“ и задрасканата стара цена до нея, ако
има. Едно място — `productCardData()`/компонентът на картата, не по
блокове. Ако някога има продукт с варианти и различни цени, „от“ ще се
върне като изрично поле, не автоматично.

## 4. Проверка

- `npm run import:all --dry-run` → за новите папки пише „ще създаде и
  публикува“; за съществуващите — без промяна.
- Страницата на 110W Lightweight: сравнителната таблица без „Няма
  снимка“.
- `/kategorii/solarni-paneli` и началната: картите показват „159,00 €“,
  не „от 159,00 €“.
- Нищо по вече внесените продукти.
