# Задача: отделен цвят за бутоните

Засяга `src/app/(frontend)/globals.css`, `src/globals/Design.ts` и
компонентите с бутони.

---

## Какво се иска

Бутоните да са тъмни, като на eu.ecoflow.com, но **зеленото на марката да
остане** за акценти — етикети за наличност, контур при навигация с
клавиатура, дребни подчертавания.

Сега и двете са едно и също поле (`--color-brand`), затова смяната на
бутоните убива зеленото навсякъде.

---

## 1. Нови токени в `globals.css`

В блока `@theme`, до съществуващите цветове на марката:

```css
/* ── Бутони ── */
--color-cta: #111111;
--color-cta-hover: #333333;
--color-cta-text: #ffffff;
```

`--color-brand` и `--color-brand-dark` **остават непроменени** —
`#00a862` и `#00854e`. Те вече не са за бутони, а за акценти.

Оправи и коментара над тях, за да не подвежда следващия.

---

## 2. Полета в админа

В `src/globals/Design.ts`, **нов раздел „Бутони"** след „Марка":

```
hex('cta', 'Фон на бутоните', '#111111', 'Основните бутони — „Купи сега“, „Към магазина“.')
hex('ctaHover', 'Фон при посочване', '#333333')
hex('ctaText', 'Цвят на текста в бутоните', '#ffffff')
```

Добави ги и в `DESIGN_TOKEN_MAP`, за да стигат до CSS променливите:
```
cta → --color-cta
ctaHover → --color-cta-hover
ctaText → --color-cta-text
```

Смени и описанието на полето „Основен цвят" в раздел „Марка" — сега пише
„Бутони и акценти", а вече е само за акценти.

---

## 3. Къде се сменя

Мини през компонентите и замени **само там, където е истински бутон**:

`bg-brand` → `bg-cta`
`hover:bg-brand-dark` → `hover:bg-cta-hover`
`text-white` върху бутон → `text-cta-text`

Места за проверка:
- `src/components/Header.tsx` — бутонът „Към магазина"
- `src/components/ProductCard.tsx`
- `src/app/(frontend)/products/[slug]/page.tsx` — бутонът за покупка
- `src/components/blocks/*.tsx` — бутоните в банерите и картите
- `src/components/Footer.tsx` — бутонът на бюлетина
- `src/app/(frontend)/page.tsx` — бутонът „Към админ панела" при празна база

**Не пипай:**
- Контура при навигация с клавиатура в `globals.css`
  (`:focus-visible { outline: 3px solid var(--color-brand) }`) — остава зелен.
  Зеленото се откроява по-добре върху тъмен бутон, отколкото тъмно върху тъмно
- Етикети, значки и текстови акценти, които ползват `text-brand` или
  `border-brand` — те остават зелени
- Цветовете `--color-accent`, `--color-info`, `--color-alert`

Разликата е проста: **фон на нещо, което се натиска → тъмно. Всичко
останало със зелено → остава.**

---

## 4. Правила

- Никакви нови зависимости
- Не променяй размери, отстояния и заобляния на бутоните — само цвета

**След промяната:**
```
npm run generate:types
npm run migrate:create
```

---

## 5. Как да разбереш, че е готово

- В админа, Настройки → Дизайн, има раздел „Бутони" с три полета
- Бутоните на сайта са тъмни, без да е пипано нищо в админа
  (стойностите по подразбиране работят)
- Смяна на „Фон на бутоните" в админа се вижда след запис, без нов билд
- Контурът при натискане на Tab е зелен, не тъмен
- Ако някъде е останало зелено копче — намери го и го смени; ако някъде
  зеленото е акцент, а не бутон — остави го
