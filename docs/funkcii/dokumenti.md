# Документи (task-dokumenti.md, 29.10.2026 →)

Раздел „Документи": ръководствата, кратките ръководства, инструкциите за безопасност и за монтаж на EcoFlow — официалните на български, нашите преводи и оригиналите. Правилата накратко — `.claude/rules/dokumenti.md`; процедурата — skill `nov-dokument`.

## Етапите

1. **Опис** (`1ac70f1`) — центърът за сваляне на EcoFlow EU: 153 уникални адреса от 33 страници (`content/dokumenti/raw.tsv`, проверени по SHA-256 срещу браузъра) + 5 официални BG ръководства извън центъра. `scripts/dokumenti/opis.py` → `opis.json`/`opis.csv`: вид, език, продукти (само видимите в сайта по снимката `produkti-sarvar.tsv`), скрит, източник на BG, несигурна връзка, бележка. API-то на центъра връща празно без заглавките на сайта — затова описът е от страниците.
2. **Сваляне** (`a201543`) — `svali.py`: 111 адреса → 97 файла (SHA-256; EcoFlow сочи един файл от няколко заглавия), 1595 стр., без сканирани. Официалните BG — `bg-pdf.mjs` с инсталирания Chrome (`playwright-core`): manuals.ecoflow.com рендира в браузъра; BG има, ако `/_next/data/<build>/eu/product/<slug>.json?lang=bg_BG` не е празно. 26 ръководства (808 стр.); скрити менюто, страничното съдържание, чатът; горе — бележка с източника и датата. `--en` → 20 английски онлайн ръководства без BG (оригиналите до преводите).
3. **Сайтът** (`f15146e`) — колекция `documents` (upload в `media/dokumenti`, само PDF, `orderable`), раздел на продуктовата страница, `/dokumenti`, sitemap, robots, футър (`futar-dokumenti.ts`), nginx.
4. **Вносът** — `import:dokumenti:server`: 143 документа (26 официални BG, 117 оригинала), 70 скрити.
   Корекции след Cowork (`1b26dca`): nginx 50 MB; общ документ → име с всички продукти; по-старото ръководство за монтаж на STREAM Ultra & Pro (V1.0 en+de+fr) — скрито.
5. **Преводи** — на партиди (виж по-долу).

## Преводите

- `izvleci.py` → `prevodi/spisak.json`: всеки оригинал без официален BG (109: 53 видими, 56 скрити), в реда на превода (електроцентрали → GLACIER → RAPID → панели → STREAM → стойки → WAVE → кабели; после скритите); английският текст по страници в `izvlecheni/`. Езиковият филтър е по абзаци за всички — описаните като „EN" често са многоезични (DELTA Pro Ultra: 185 хил. знака в 28 стр., английските — 16 хил.).
- Преводачът пише `<id>.en.md` (точно английското, което превежда — сверено с PDF-а) и `<id>.md` по `FORMAT.md`/`rechnik.md`.
- `prevod-pdf.mjs` проверява (числата от `.en.md` — в превода; броят на `:::danger/warning/caution/note/tip`; изречения с английски думи; покритие ≥90% на английските изречения от извлечения текст, по 4 думи) и прави PDF по `shablon.html` (Inter, логото, #F2F2F2 за предупрежденията, бележка „Превод на ДИ СИ 2008 ООД… При разлики важи оригиналът.", съдържание при > 4 стр., номера на страниците, „За България: … office@ecoflow.bg, ecoflow.bg"). PDF-ът се чете обратно с `pdftotext` (кирилица, без счупени знаци). Минал → `prevodi-gotovi.json` → вносът (`bg-prevod`, връзка „Оригинал", заглавие/продукти/„Скрит" — на оригинала).

## Решения

- Документите — по SHA-256: един файл = един документ с всичките му продукти, колкото и заглавия да има при EcoFlow.
- Скритите — вместо триене: продукт, който го няма; друг език (RU, NL, PL …) при наличен EN/BG; по-стара версия.
- PDF-ите не са в git (стотици MB) — в `content/dokumenti/` локално и в `content-server/dokumenti` на сървъра; файловете на сайта — `media/dokumenti`.
- Телефонът не се слага в преводите (само на `/kontakti`); имейлът — office@ecoflow.bg.
