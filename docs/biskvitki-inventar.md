# Бисквитки и външни заявки — инвентаризация (13 октомври 2026)

Проверено на:
- **сървъра** — 207 страници (всички от sitemap.xml + `/vaprosi`, `/kontakti`, `/oferta-za-firmi`, `/vhod`, `/admin`, `/admin/login`, `/tarsene`): заглавия `Set-Cookie` и външни `src` / `href` / `srcset` / `poster` / CSS `url()` в HTML-а;
- **браузър** (локално, копие на базата) — начална, продукт, категория с филтър, `/vaprosi` с търсене, `/kontakti`, `/oferta-za-firmi`, `/za-ecoflow`, после вход в админа с тестов потребител: `document.cookie`, `localStorage`, `sessionStorage`, всички заявки (`performance`);
- **кода** — `grep` за `<iframe`, `<script`, `<video`, външни адреси, `document.cookie`, `localStorage`, `sessionStorage`; CSS и JS файловете на билда.

## Резултат: посетителят не получава нищо

На публичните страници: **0 бисквитки, 0 записа в localStorage / sessionStorage, 0 заявки към чужди домейни.** Шрифтът (Inter) е самохостнат от `next/font`; снимките и видеото са от нашата Медия; няма iframe, видео от YouTube, карти, Analytics, пиксели. Магазините имат само **линк** към Google Maps — заявка няма, докато човек не щракне.
