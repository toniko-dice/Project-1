# Задача: внос на всички продукти с една команда

Сега вносът е по един продукт: `npm run import:product <slug>`. При
промяна, която засяга много продукти (подзаглавия, общи полета), е
неудобно да се изреждат.

## 1. `npm run import:all`

- Минава през всички папки в `content/`, които съдържат
  `sadarzhanie.json`, по азбучен ред, и вика същата логика като
  `import:product` за всяка — нищо не се дублира, същите правила
  (публикуван → остава публикуван; нов → чернова; снимките се
  преизползват от Медия по име).
- Папки без `sadarzhanie.json` (напр. `referentsia/`) се прескачат.
- Една грешка не спира останалите: продуктът се отбелязва като
  неуспешен, вносът продължава, накрая има обобщение — таблица
  „slug | резултат (създаден като чернова / обновен и публикуван /
  обновен, остава чернова / ГРЕШКА: …) | липсващи файлове“.
- По избор `--only river-3-plus,river-3-ups` (списък) и `--dry-run`
  (само проверява файловете и изписва какво би направил, без запис).
- `import:product` остава както е.

## 2. Проверка

`npm run import:all --dry-run` изписва всички 12 папки без грешка;
`npm run import:all` обновява петте RIVER продукта с новите
подзаглавия (river-3-ups, river-3-plus, river-3-max-plus-wireless —
остават публикувани; river-3-plus-wireless, river-3-max-plus — нови
чернови), а DELTA продуктите се обновяват без промяна и остават
публикувани. Опиши командата в CLAUDE.md.
