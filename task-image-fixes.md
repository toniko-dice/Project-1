# Задача: подредба „текст отгоре, снимка отдолу" и неизрязани размери

Проверено на живо върху `/products/delta-3-classic`. Два проблема с една
обща причина — размерите на изображенията изрязват, а подредбите не
покриват най-честия случай от оригинала.

---

## 1. Нова подредба `stacked` в `FeatureSection`

### Проблемът
`image-full` слага текста **върху** снимката с полупрозрачен слой
(`bg-black/50` или `bg-white/40`) и налага `aspect-[16/9]` с `object-cover`.

За снимка, която сама съдържа текст и графики — колаж с шест плочки,
екрани на приложение, три панела един до друг — това ги затъмнява, изрязва
и пише отгоре. На оригинала такива секции са **заглавие и текст отгоре,
снимка отдолу в цял размер**, една след друга.

### Промяна в `src/blocks/product/FeatureSection.ts`
Добави четвърта стойност в `layout`:
```
{ label: 'Текст отгоре, снимка отдолу', value: 'stacked' }
```

### Промяна в `src/components/blocks/product.tsx`
При `stacked`:
- заглавие, подзаглавие, текст и показатели — отгоре, центрирани,
  `max-w-3xl`
- под тях снимката на **пълна ширина на контейнера**, без изрязване:
  `width`/`height` от `mediaDims`, не `fill`; без наложен `aspect`;
  `object-contain` или просто `h-auto w-full`
- **без полупрозрачен слой**
- тъмната тема сменя само фона на секцията и цвета на текста, не пипа
  снимката

`image-full` остава както е — става за истински банер с кратък надпис.
Но смени `bg-white/40` на `bg-white/20` — сегашният бял слой прави
светлите снимки да изглеждат избелели.

## 2. Размери, които не изрязват

### Проблемът
В `src/collections/Media.ts` всички размери имат ширина **и** височина с
`position: 'centre'` — тоест изрязват до точното съотношение:

| Размер | Изрязва до | Ползва се за |
|---|---|---|
| `thumbnail` | 400×400 | добре — миниатюри |
| `card` | 768×768 | **грешно за галерията** — разтяга се до 1920 |
| `banner` | 1920×900 | **грешно за секциите** — портретен колаж 1680×2037 губи две трети |
| `wide` | 2400×800 | банери на началната |

### Добави два размера, които пазят съотношението
Само ширина, без височина — Sharp пази пропорцията:
```ts
{ name: 'content', width: 1600, formatOptions: { format: 'webp', options: { quality: 82 } } },
{ name: 'large', width: 2000, formatOptions: { format: 'webp', options: { quality: 82 } } },
```

Без `position` — няма изрязване, няма нужда от позиция.

### Смени къде се ползват

| Място | Сега | Да стане |
|---|---|---|
| `page.tsx` — галерия | `card` | `large`, с резерва оригинала |
| `product.tsx` — `FeatureSection`, всички подредби | `banner` | `content` |
| `product.tsx` — `TabbedShowcase` снимки | `banner` | `content` |
| `product.tsx` — `ComparisonTable` колони | `card` | остава — квадратът там е подходящ |
| `product.tsx` — `InTheBox` | `card` | остава |
| `TabbedShowcase` икони | `thumbnail` | остава |

`mediaUrl` вече връща оригинала, ако размерът липсва — затова
съществуващите снимки ще продължат да работят и без преобразуване,
само ще ползват оригинала.

### Атрибутът `sizes`
Където снимката е на пълна ширина на контейнера, `sizes` да е
`(max-width: 1408px) 100vw, 1408px` — контейнерът е `max-width: 88rem`.
Сега пише `100vw` и браузърът дърпа по-голяма снимка, отколкото показва.

## 3. Проверка на скрипта за внос

В `content/delta-3-classic/sadarzhanie.json` колоните на сравнителната
таблица вече имат `image` и `imageAlt`. Провери, че `import-product.ts`
качва и тях — те са вложени в `columns[]`, а не на първо ниво.

Ако не — общата функция за изображения да обхожда и вложените масиви.

---

## 4. Правила

- Не пипай `ProductAnchorNav.tsx`, `ProductTabs.tsx`, `ProductGallery.tsx`
  — проверени са и работят
- Не преобразувай старите изображения — резервата към оригинала ги покрива
- Няма миграция: новите размери не са промяна в схемата на базата
- След промяната в `FeatureSection.ts`: `npm run generate:types`

---

## 5. Как да разбереш, че е готово

Пусни вноса наново — `npm run import:product delta-3-classic` — за да влезе
обновеното съдържание. После на `/products/delta-3-classic`:

- Колажът (първата секция) се вижда **цял**, портретен, без текст върху него
  и без бял слой; заглавието е над него
- Секциите с приложението и с трите панела — същото
- Галерията е остра на широк екран, не разтегната
- В сравнителната таблица колоната DELTA 3 Classic има снимка
- Никоя снимка в секциите не е изрязана отстрани или отгоре
- В мрежовия панел на браузъра заявките за снимки са към `-1600` или
  `-2000` размерите, не към `-1920x900` или `-768x768`
