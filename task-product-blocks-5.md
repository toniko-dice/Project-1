# Задача: „В кутията“ с раздели по модел + подравняване на галерията с buy box-а

## 1. `inTheBox` — раздели

На страници с няколко модела (RIVER 3 Plus / Max / Max Plus (Wireless))
EcoFlow показват „What's in the box“ с раздели по модел. Собственикът
иска същото.

- Ново поле `groups` (array, по избор): `label` (име на раздела) +
  `items` (същите полета като сегашните `items`). Ново поле
  `defaultGroup` (number, по избор) — кой раздел е отворен при
  зареждане (индекс от 0; вносът го подава).
- Ако `groups` е празно → показва се `items` както досега (Classic,
  DELTA 3, Max, Max Plus, Pro 3 не се променят). Ако има `groups` →
  ред с раздели над картите (същият стил като `tabs-top` при
  `tabbedShowcase`), под тях картите на активния раздел. `items` не се
  показва.
- Вносът приема `groups[].items[].image` по същото правило за
  файлове (преизползване по име от Медия).
- Миграция: `npm run migrate`.

## 2. Галерията и buy box-ът — на една линия

Прикачената снимка: галерията вляво започва по-високо от заглавието и
завършва по-ниско от текста вдясно. При EcoFlow двете колони започват
на една и съща височина.

- Двете колони (галерия + информация) с еднакъв горен ръб — заглавието
  H1 започва на височината на горния ръб на галерията; без разлика в
  отстъпите между колоните.
- Галерията е квадрат по ширината на колоната (както е), точките за
  навигация под нея. Информационната колона не се разтяга — ако е
  по-къса, остава горе (top-aligned), не се центрира.
- Прилага се за всички продукти — това е компонентът на страницата,
  не съдържание.

## 3. Внос

кутията“ с три раздела, активен „RIVER 3 Max Plus (Wireless)“.
