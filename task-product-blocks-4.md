# Задача: заглавие по избор в FeatureSection + внос на DELTA 3 Plus + повторен внос на DELTA 3

## 1. `featureSection.heading` — по избор

Главният банер на DELTA 3 (`PC_0_2_D3P_Main_KV.jpg`) на EcoFlow е без
заглавие — то стои на следващата секция (колажа). Сега `heading` е
`required: true` и блокът не може да е само снимка.

- `required: false`. При празно заглавие секцията показва само снимката
  (и `body`, ако има), без празно място за заглавие.
- `admin.components.RowLabel`/`blockLabel('heading')`: при празно
  заглавие надписът на реда в админа да е името на файла на снимката,
  за да се различават блоковете.
- Няма миграция.

## 2. Внос

1. `npm run import:product delta-3` — обновен JSON: главният банер без
   заглавие, нова секция „колаж“ (`1_1_89e83263…jpg`) със заглавието,
   „В кутията“ вече с 3 елемента (без кабел за автомобил — проверено по
   картинката на EcoFlow). Продуктът е публикуван → остава публикуван.
2. `npm run import:product delta-3-plus` — нов продукт, чернова.
   Всички снимки са същите като при DELTA 3 (страницата на EcoFlow е
   обща) — вносът ги преизползва от Медия по име, нищо не се качва
   повторно. Категория `delta-3-seriya`.
3. Повторен внос на `delta-3` не е нужен за сравнението — колоната
   `delta-3-plus` се връзва при вноса на Plus (`productSlug`), а
   колоната Plus в DELTA 3 и Classic ще се върже при следващия им внос;
   ако не се връзва автоматично в обратна посока — пусни
   `import:product delta-3` и `delta-3-classic` още веднъж накрая.
