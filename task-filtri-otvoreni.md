# Задача: „Отворен по подразбиране“ за всеки филтър

Прочети целия файл преди да започнеш.

Сега кои филтри са отворени при зареждане на страницата е решено в кода (Цена и Категория). Собственикът иска да го решава сам от админа.

## Какво
- В Global „Подредба на филтрите“ (`filter-order`) добави на всеки ред отметка **„Отворен по подразбиране“** (checkbox).
- Миграция/seed: отметката е включена **само на Наличност**; на всички останали (включително Категория и Цена) — изключена. Ако редовете вече съществуват, само добави стойностите, без да пипаш реда им.
- На сайта филтърът се показва отворен при зареждане, ако отметката е включена. Посетителят може да го затвори/отвори както сега.
- **Мобилно:** в панела „Филтри“ важи същото.
- Нов атрибут, който още го няма в списъка (показва се автоматично преди Съвместимост), е **затворен**.
- Под полето в админа: „Отметнатите филтри са отворени, когато се зареди страницата.“

## Проверка
- `/kategorii/kabeli`: само Наличност е отворена; Конектор, Дължина, Съвместимост и Цена — затворени.
- `/kategorii/delta-seriya/aksesoari`: само Наличност е отворена; Категория също е затворена.
- Включи отметката на „Дължина“ в админа → на сайта е отворена след презареждане. Върни я.
- `npm run build` минава.
