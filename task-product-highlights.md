# Задача: акценти в кутията за покупка

Малка задача. Засяга `src/collections/Products.ts` и
`src/app/(frontend)/products/[slug]/page.tsx`.

**Прави се преди `task-import-product.md`** — файлът със съдържанието вече
съдържа тези данни и скриптът ще ги търси.

---

## Какво липсва

На оригинала, в дясната колона под цената и вариантите, стои кратко
обобщение — три акцента с удебелено заглавие и пояснение след него, плюс
разгъващ се линк „Overview" под тях.

Това **не е секция от страницата.** Стои в горната част, при цената и
бутона, и се вижда без скролване. Затова е поле на продукта, а не блок.

Пропуснато е при първоначалното описание на страницата.

---

## 1. Ново поле в `Products`

В раздел „Основни", веднага след полето `tagline`:

```
name: 'highlights'
type: 'array'
label: 'Акценти под цената'
labels: { singular: 'Акцент', plural: 'Акценти' }
maxRows: 5
admin: {
  description: 'Кратките изречения в кутията за покупка, под цената. Три до пет са достатъчни — това е първото, което клиентът чете.',
  components: {
    RowLabel: {
      path: '@/components/admin/RowLabel#RowLabel',
      clientProps: { field: 'title', fallback: 'Акцент' },
    },
  },
}
fields: [
  { name: 'title', type: 'text', required: true, label: 'Заглавие' },
  { name: 'text', type: 'textarea', required: true, label: 'Пояснение' },
]
```

---

## 2. Изчертаване

В дясната колона на продуктовата страница, **между цената и бутона за
покупка**.

- Списък, всеки ред: заглавието удебелено, поясненията след него с
  нормален шрифт
- Приглушен фон, за да се отделя от останалото — както в оригинала
- Ако продуктът няма акценти, блокът не се показва изобщо, без празно
  място

**Разгъването** от оригинала („Overview ⌄") не го прави. При три реда
няма какво да се крие, а скритият текст е по-лош за търсачките. Ако някой
ден акцентите станат много, ще се добави.

---

## 3. Правила

- Не пипай нищо друго на продуктовата страница
- Никакви нови зависимости

**След промяната:**
```
npm run generate:types
npm run generate:importmap
npm run migrate:create
```

---

## 4. Как да разбереш, че е готово

- В админа, в раздел „Основни", има „Акценти под цената" с бутон за
  добавяне на ред
- Редовете показват заглавието си, не „Акцент 01"
- На продуктовата страница акцентите се виждат между цената и бутона
- Продукт без акценти изглежда както преди, без празно място
- На 375px ширина текстът се пренася нормално и нищо не излиза встрани
