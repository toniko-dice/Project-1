# Задача: адресът на снимката да се сменя при промяна

Засяга само `src/lib/media.ts`.

---

## Проблемът

При презаписване или изрязване на снимка в админа Payload презаписва
файла, но **името остава същото.** Сайтът и браузърът пазят снимките по
адрес — същият адрес означава „нищо ново", и старата версия остава:

- браузърът не я тегли пак
- Next.js пази оптимизираната версия в `.next/cache/images`, пак по адрес

Проверено на живо: след смяна на изрязването в админа сайтът показва
предишния вариант, докато не се изчисти кешът ръчно.

---

## Решението

Адресът на снимката да носи времето на последната ѝ промяна като параметър.
Промени ли се снимката, променя се и адресът — и всички кешове я теглят
наново.

В `src/lib/media.ts`, функцията `mediaUrl`:

```ts
export const mediaUrl = (value: MaybeMedia, size?: ...): string | null => {
  if (!value || typeof value === 'number') return null

  const base = size && value.sizes?.[size]?.url ? value.sizes[size]!.url! : value.url
  if (!base) return null

  // Времето на промяна като част от адреса. Презапис или изрязване в
  // админа сменя updatedAt → сменя се адресът → браузърът и кешът на
  // Next.js теглят новата версия вместо старата.
  const stamp = value.updatedAt ? Date.parse(value.updatedAt) : 0
  return stamp ? `${base}?v=${stamp}` : base
}
```

`updatedAt` идва от Payload за всеки документ в Медия и се обновява при
всяка промяна, включително изрязване.

---

## Внимание при `next/image`

`next/image` подава адреса на оптимизатора като параметър `url=`.
Провери, че `?v=` се запазва вътре в него и оптимизаторът го вижда като
различен адрес — иначе кешът на Next пак ще връща старото.

В `next.config.ts` няма `remotePatterns` за локалните пътища, така че
адресите с параметър минават. Ако Next откаже, добави в `images`:

```ts
localPatterns: [{ pathname: '/api/media/**', search: '' }],
```

като `search: ''` позволява всякакви параметри.

---

## Правила

- Не пипай нищо друго — `mediaAlt` и `mediaDims` остават както са
- Никакви нови зависимости
- Няма миграция, няма нова схема

---

## Как да разбереш, че е готово

- В изходния код на страница адресите на снимките завършват на `?v=`
  и число
- Промяна на изрязването в админа и обикновено презареждане на сайта
  (не Ctrl+Shift+R) показва новата версия веднага
- Схемата Schema.org (`application/ld+json`) и og:image също носят
  параметъра — те минават през същата функция
- Няма грешки в конзолата за отхвърлени адреси на изображения
